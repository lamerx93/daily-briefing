# Daily Briefing

A daily briefing on AI, AI agents and the Indonesian credit market, built as a small web app
that works offline once it has been opened.

Open it at https://lamerx93.github.io/daily-briefing/

On an iPhone: open the link in Safari, tap Share, then Add to Home Screen.

Each day's edition is a JSON file in `data/`. `CLAUDE.md` describes how an edition is written
and published.
